# Tic Tac Toe Game

A beautiful Flutter implementation of the classic Tic Tac Toe game with dark theme and smooth animations.

## Features

- Dark mode UI with Material 3 design
- Score tracking
- Win/draw detection
- Animated game cells
- Responsive design
- Game state dialogs
